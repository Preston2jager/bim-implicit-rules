# 实验六:姿态蒸馏辅助头(pose distillation aux head)

**Run**: `2026JUL112325`,menu 6 重训,2026-07-12 14:51 → 17:46(约 2.9 h,42/100 epoch 早停)
**归档**: 本目录(评估报告 + split metrics + `best_42` checkpoint);run 内副本在 `output/experiments/scalar_s_pose_w0.1/`

---

## 1. 背景与动机

第五轮(scalar_s,Name 去标识)确立了两个事实:

1. **能力下限**:仅用门损失训练,holdout 侧向准确率 70.5%,语义规则 64.5%,且失败呈"每个 (copy×房间状态) 单元整体镜像"的全对全错模式。
2. **能力上限(可证)**:线性 ridge probe 仅在训练 copy 上拟合 z→质心,holdout 误差 11.3 cm、R²=0.9994;probe 质心 + 拓扑的手工管线在全部 4824 张 holdout 图上 100% 复现三条规则。

即:**embedding 里线性可读的位姿信息可以完美迁移到未见变换,但 Graphormer 没有自发蒸馏出这个读出**。实验六的假设:把该线性读出作为辅助监督蒸馏进节点表示,注意力层就能获得相对几何/手性信息。

另外,7-12 上午一次配置事故(run config 快照缺 `pose_distill_weight` 键,辅助头静默未启用)意外产生了一次**同条件重跑**,给出了单次运行的噪声带:总准确率 66.3–70.5%(±4 pp),单规则 ±17 pp,单 copy 最大 ±38 pp。这是判断本轮提升是否为真信号的基准。

## 4. 分析

### 4.1 为什么有效

蒸馏损失强迫每个节点的最终表示保持"质心线性可读"。probe 已证明这个读出在未见变换下成立(线性 ⇒ 对刚体变换协变),于是注意力层拿到了可靠的相对几何,三条规则同时受益——包括与位姿无直接关系的六窗槽位精度(anchor 组合中的 axis 方向感知变准)。

### 4.2 训练动态

两种设置的突破点几乎相同(val 从 ~4 的均值基线跌破 1:无 pose ep16,pose ep17-18),差别在**后段**:pose 版从 ep28 起 val 稳定进入 1e-3 量级并干净下降(42 epoch 早停),无 pose 版反复震荡到 ep66。辅助损失没有拖慢主任务,反而平滑了后期 loss 面。Seen 误差 0.57→1.61 cm 是正则化的正常代价(槽距 0.95 m,可忽略)。

### 4.3 辅助损失已到达线性下限(对调权重很重要)

收敛段 Train(含 0.1×pose)≈ 1.2–1.9e-3,Val(纯门)≈ 3.5–5e-4 → 残余 pose 项 ≈ 0.9–1.5e-3,即原始 pose 损失 ≈ 0.009–0.015 loss 单位。probe 的不可约下限(11.3 cm 世界误差,scale 0.1、loss×100)折算 ≈ 0.012——**两者吻合:pose head 在 weight=0.1 时已学到其线性可达的极限精度**。

推论:继续加大权重**不会让位姿读出更准**(已饱和),只会改变梯度/容量分配——迫使网络更早、在更多容量上维持位姿可读性。收益只能来自这一间接渠道,预期是次线性的。

## 5. pose_distill_weight 该加到多大

用 epoch-1 的量级估算梯度配比:Train 27.2(含 aux)− Val 19.5(纯门)→ 原始 pose 损失 ≈ 77,门损失 ≈ 19.5。

| weight | 早期 aux:door 梯度比 | 判断 |
|---|---|---|
| 0.1(本轮) | ≈ 0.4 : 1 | 已验证有效,aux 已达线性下限 |
| **0.3(推荐下一点)** | ≈ 1.2 : 1 | 两任务均衡,间接收益空间最大、风险最小 |
| 1.0(上限压力测试) | ≈ 4 : 1 | 早期梯度被 pose 主导,门任务突破可能推迟、早停(纯门 val)变慢;仅当 0.3 出现单调收益时再试 |
| >1 | — | 不建议:pose 已饱和,纯付代价 |

**判定准则**:0.3 若使语义 0% 镜像单元减少(5→更少)→ 方向正确,可试 1.0;若与 0.1 无差别(±噪声带)→ 剩余镜像**不是蒸馏强度问题**,而是注意力无法从位姿组合出稳定手性,应转向增加旋转 copy 数或旋转协变的相对特征(如节点对相对方位编码),或作为负结果如实报告。

## 6. 结论与下一步

1. **核心结论**:姿态蒸馏把 holdout 侧向准确率从 70.5%(噪声带 66–70)推到 **86.6%**,三条规则与全部 6 个未见变换同步受益;probe 证明的"线性位姿读出可迁移"通过蒸馏成功转化为模型能力。消融三元组(R5 / R5b / R6)干净可用于论文。
2. 剩余缺口(86.6% vs probe 管线 100%)集中在语义规则手性:5 个整体镜像单元 + 若干部分翻转单元。
3. 下一步:`pose_distill_weight: 0.3` 重跑(menu 6,改 run config,开训确认 ENABLED 日志);按 §5 判定准则决定后续。
