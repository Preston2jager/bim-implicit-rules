# 实验三：位姿蒸馏辅助损失（权重扫描）

**设定**：run `2026JUL112325`（81 copies、去身份化、scalar_s 头），同一批嵌入与图，
仅改 `training.graphormer.pose_distill_weight` ∈ {0, 0.1, 0.3} 重训。
蒸馏头 = 末端对每个真实节点加线性头预测其质心（坐标只作辅助监督目标、从不作输入；
合成目标门被 mask；辅助项只进训练 loss，Val/Test 与早停阈值保持纯门损失）。

**噪声带**：w=0 有两次同数据同配置的独立运行（一次配置快照缺键导致的意外重跑），
holdout 整体侧别 70.5% vs 66.3%，per-copy 语义摆动最大 ±38pp
→ **单次运行 <~5pp 的整体差异视为噪声**。

**结论**：
1. w=0→0.1：整体 70.5→86.6%（远超噪声带），六窗 exact-slot 52.3→77.8%，
   收敛更快（42ep vs 54/66ep）——探针证明存在的线性位姿读出被蒸馏进表示后，
   注意力层获得了相对几何。
2. w=0.1→0.3：六窗侧别 89.4→95.0%、exact-slot 77.8→86.3%（真提升）；
   整体 +1.6pp 在噪声带内；语义规则 75.6→71.1% 且零 cell 完全洗牌
   （崩溃与恢复的 (copy×room) cell 互换）→ 按预登记判据，
   **语义手性不是蒸馏强度问题**，w=1.0 无须再跑。
3. 辅助损失在 w=0.1 时已达线性下限（train−val 残差 ≈ 0.1×探针地板），
   加大权重只改变梯度配比。
